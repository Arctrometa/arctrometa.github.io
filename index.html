Genshin Impact India Abyss Tournament Rules

Match Structure & Format

Double Elimination, 1v1 competitive speedrun matches. Both players run the exact same Spiral Abyss Floor 12 Chambers. The player with the fastest clear time wins the match.

Resets: Unlimited resets are permitted, but all restarts add directly to total wall-clock run time. Opponents do not wait.

The 6.0 Limited Cost Ceiling

Each individual half (First Half and Second Half) has a strict maximum limit of 6.0 Limited Cost.

  • 4★ Characters & Weapons: 0.0 Cost regardless of constellation or refinement level.
  • 5★ Characters (Weighted Cost Table): Each 5★ character uses the official tournament weighted C0–C6 cost progression table.
  • 5★ Limited Weapons: 1.0 Cost base (R1 = 1.0). Each refinement adds +1.0 Cost (R5 = 5.0).
  • 5★ Standard Weapons: 0.0 Cost base (R1 = 0.0). Each refinement adds +0.5 Cost (R2 = 0.5, R3 = 1.0, etc.).
