Genshin Impact India Abyss Tournament Rules

Match Structure & Format

Double Elimination, 1v1 competitive speedrun matches. Both players run the exact same Spiral Abyss Floor 12 Chambers. The player with the fastest clear time wins the match.

Resets: Unlimited resets are permitted, but all restarts add directly to total wall-clock run time. Opponents do not wait.

The 5.0 Limited Cost Ceiling

Each individual half (First Half and Second Half) has a strict maximum limit of 5.0 Limited Cost.

  • 4★ Characters & Weapons: 0.0 Cost regardless of constellation or refinement level.
  • 5★ Limited Characters: 1.0 Cost base (C0 = 1.0). Each subsequent constellation adds +1.0 Cost (unless discounted by event exemptions).
  • 5★ Standard Characters: 0.0 Cost base (C0 = 0.0). Each subsequent constellation adds +0.5 Cost (unless discounted by selectors/events).
  • 5★ Limited Weapons: 1.0 Cost base (R1 = 1.0). Each refinement adds +1.0 Cost.
  • 5★ Standard Weapons: 0.0 Cost base (R1 = 0.0). Each refinement adds +0.5 Cost (R2 = 0.5, R3 = 1.0, etc.).

Event & Selector Constellation Exemptions

Constellations accessible for free via the Anniversary Selectors and "To Temper Thyself and Journey Far" event feature universal discounts across all participant accounts:

  • Dual-Event Limited Pool (5 Characters): Baizhu, Chiori, Clorinde, Nilou, Tartaglia
    Because these 5 characters are obtainable for free through both the Anniversary Selector and the Temper Thyself event, both their C1 and C2 constellations are 0.0 Cost!
    Progression: C0 = 1.0 | C1 = 1.0 | C2 = 1.0 | C3 = 2.0 | C4 = 3.0 | C5 = 4.0 | C6 = 5.0.
  • Anniversary Selector Limited (1 Character): Varesa
    Available via the Anniversary Selector. Her C1 constellation is 0.0 Cost (C1R0 Varesa = 1.0 Cost total).
  • Yearly Standard Selector (8 Characters): Dehya, Diluc, Jean, Keqing, Mona, Qiqi, Tighnari, Yumemizuki Mizuki
    Present in both the Yearly Standard Selector and Temper Thyself. Both C1 and C2 are 0.0 Cost!
    Progression: C0 = 0.0 | C1 = 0.0 | C2 = 0.0 | C3 = 0.5 | C4 = 1.0 | C5 = 1.5 | C6 = 2.0.
